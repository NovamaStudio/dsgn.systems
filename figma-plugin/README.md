# dsgn theme — Figma plugin

Adds a project theme (brand colour, greys, status colours, font) to the dsgn Figma library as a mode, with the same contrast guarantee as the code. Same controls as the Theme customizer in the documentation, and it accepts a theme code copied from there.

## Install (once)

You need the Figma **desktop app**; plugins in development cannot be installed in the browser.

1. On GitHub, open the repository, click **Code → Download ZIP** and unzip it.
2. In the Figma desktop app, open any design file and choose **Plugins → Development → Import plugin from manifest…**
3. Pick `manifest.json` in the unzipped `figma-plugin` folder.

After a new dsgn version, repeat steps 1–3 with the new download.

## Use

1. Open the **dsgn library file** (where the variables live) and run **Plugins → Development → dsgn theme**.
2. Pick the brand colour, or open **Paste a theme code** and paste the code from the web customizer.
3. Click **Add to Figma**. The theme becomes a mode in the Primitives collection (and Typography, when a font is set).
4. Select a frame, and in the Variables mode picker choose the theme for Primitives. Publish the library so project files get it.

Themes you added are listed at the bottom of the plugin: **Edit** loads one back, **Remove** deletes its mode.

Generated by `build/plugin.mjs`; do not edit these files.
